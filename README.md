## Key Features

- Customizable Safe Browsing Settings: Parents can configure browsing preferences for their children.

- Real-Time AI Content Filtering: Dynamically blocks inappropriate content.

- Educational Resource Recommendations: Restricts distractions while promoting learning.

- Phishing and Scam Protection: Detects and prevents malicious sites.

- Seamless Updates & Enhanced Security: No device dependency required, works on any platform Linux, Windows, MacOS.

- Integration with Web Browsers & Parental Control Apps: Ensures easy implementation.

- Open-Source: Utilizes free and open-source tools.

## How To Use

To clone and run this application, you'll need [Git](https://git-scm.com) and [Python](https://www.python.org/downloads/) installed on your computer. From your command line:

```bash
# Clone this repository
$ git clone https://github.com/deadpoet11/safenet

# Go into the repository
$ cd safenet

# Install dependencies
$ pip install -r requirements.txt

# Run the application
$ python app.py
```

> **Note**
> If you're using Linux Bash for Windows, [see this guide](https://www.howtogeek.com/261575/how-to-run-graphical-linux-desktop-applications-from-windows-10s-bash-shell/) or use `node` from the command prompt.
